# Artifact Design Profile

## Artifact intent

A compact Markdown decision aid that can be scanned before a learner commits time or money. It should feel like a careful shortlist, not a catalogue.

## Reading design

- Start with the scoped outcome and the trade-off behind the choices.
- Use a small field table for each resource; keep rationale and use advice in short prose.
- Put the recommended order before the seven-day plan so dependencies are visible.
- Use one plan table with short, action-led rows and observable outcomes.
- Keep links descriptive, headings topic-specific, and emojis optional rather than structural.

## Avoid

- repetitive praise, long review summaries, badge-like ratings, or dense comparison grids;
- generic headings that could fit any topic;
- raw citation dumps, affiliate-style language, or references to screenshots that were not gathered;
- padding every day to two hours when a shorter task is sufficient.
