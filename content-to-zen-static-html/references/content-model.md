# 内容模型（仅 A2）

最小模型；HTML 正文片段是内容，不是模板：

```json
{
  "title": "文档标题",
  "entries": [
    {"title": "第一章", "html": "<p>保留完整正文，使用<strong>语义标签</strong>。</p>"},
    {"title": "第二章", "html_file": "parts/chapter-2.html"}
  ]
}
```

文档可选字段：brand（默认 title）、kicker、subtitle、lede、footer。没有来源信息就省略，不编造落款。

条目字段：

| 字段 | 说明 |
|---|---|
| title | 必填，原文章标题，按文本转义 |
| html / html_file / markdown_file | 三选一；html 为已转换的语义 HTML；文件相对模型目录解析，支持绝对路径；markdown_file 需要 pandoc |
| id | 可省略，自动生成 entry-01 等；显式 id 须唯一且不与模板控件冲突；有原文内部链接时保持锚点一致 |
| category | 可省略，填语义分类名；按钮由脚本去重生成，未分类条目只在「全部」下显示 |
| subtitle | 可省略，已有英文标题 |
| tags | 可省略，字符串数组，从原文提取 |

不要把 Markdown 当作 html 文本塞入；先转换为标题、段落、列表、引用、表格与代码元素。正文片段会原样内嵌，因此应是本任务可信的静态内容，不含脚本、外部资源或重复 id。元数据自动 HTML 转义；脚本不负责净化不可信 HTML。

长文优先引用现有文件，避免再次输出全文。只为条目指定来源文件不等于运行时读取：文件内容在生成阶段内嵌，最终 HTML 不需要这些文件。分类、目录、编号、计数与模板装配均由脚本完成。
