# 特殊生成路径

## 手工方式 A

仅在组装器无法表达用户需求时读取 template/zen-base.html。复制本地模板，只修改内容区域；替换所有 ZEN:EDIT，删除模板头注释与示例，保留 #noResults 和 #resetFilters。每个 article.entry 的 id、data-cat 须与 #tocNav 链接、#catNav 按钮对应。不要手写 data-search，搜索从正文生成。

CSS/JS 保持复用；能在组装后定点修改的内容，不要重新输出整份文件。手工替换后运行 verify-html.py 并完成主流程的浏览器验证。

## 方式 B：内嵌 JSON

只有超过 50 个高度同构条目、且静态条目使文件明显臃肿时才考虑；默认组装器支持大量静态条目，无须因为数量自动切换。将数据放入 script[type="application/json"]，序列化时把 < 转义为 \u003c，防止正文中的 </script> 提前结束数据岛。渲染必须发生在模板交互初始化之前，交互行为须一致。

verify-html.py --expect-entries N 在无静态条目时尝试从 JSON 数据岛计数，无法解析会 WARN，必须浏览器核对。自写渲染器增加生成与验证成本，不作为提速路径。

## 风格定制

默认：日式极简负责留白与层级；侘寂负责暖白、雾灰、炭黑与纸张材质；未来科技负责单一电子蓝/青绿、等宽数字、细线与安静动效。

用户要求其他风格时，只按需要修改 :root / [data-theme="dark"] 的变量和质感层，保留结构与交互。不变量：一个主强调色，系统字体栈，暗色用炭黑，正文 ≥1.05rem（桌面约1.1rem），行高1.8～2.2，单行约65～85个中文字符以内，尊重 prefers-reduced-motion。截图确认明暗主题对比度和移动端可读性。

**对比度要算，不能只看截图。** 强调色会被用作链接与目录高亮文字，必须对背景达 4.5:1；muted 也至少 4.5:1。当前浅色值为 `--accent:#2b746f`（4.81:1）、`--muted:#676d68`（4.65:1），深色 `#5cc4bf`（8.52:1）。早期值 `#3d9d99` 只有 2.84:1，当链接文字色不达标；调色时用公式验证，别凭感觉。

## 回退边界

Markdown 快速路径按 pandoc 生成的顶层 h2 组织常规文档。嵌套原始 HTML、需要保留特殊一级标题锚点、资源内嵌、语义分类或重新组织章节，使用内容模型明确指定条目和 HTML。不得静默删除图片或降低成纯文本；将资源嵌入为 data URI/内联 SVG 后再组装。
