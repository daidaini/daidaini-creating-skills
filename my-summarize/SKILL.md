# my-summarize：文章批量摘要

给定一个包含多篇文章 `.md` 文件的目录，自动读取所有文章，用中文生成逐篇摘要，汇总输出为同目录下的 `summarize.md`。

## 参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 目录路径 | 必填，包含文章 .md 的目录 | `output/2026-03-24/` |
| `-n` | 每篇摘要句数（默认 5–8 句） | `-n 3` 表示 3 句 |
| `-o` | 自定义输出文件名（默认 `summarize.md`） | `-o digest.md` |

## 执行流程

### 1. 解析参数

从用户消息中提取目录路径和可选参数。输出文件默认为 `<目录>/summarize.md`，除非用户通过 `-o` 指定。

### 2. 发现文章文件

使用 Glob 工具列出目录下所有 `.md` 文件。排除已有的摘要文件（如 `summarize.md`、`digest.md`）。

> 注意：部分文件名含有特殊字符（如单引号 `'`）。若 Read 工具因文件名报错，改用 Bash + PowerShell 读取：
> ```powershell
> Get-Content -Path "路径\文件名.md" -Raw
> ```
> 若文件仍无法读取，根据文件名标题和上下文推断内容，并在摘要中注明「（内容根据标题推断）」。

### 3. 提取文章元数据

每篇文章通常含有 YAML frontmatter，格式如下：

```yaml
---
来源: daringfireball.net
链接: https://...
发布时间: 2026-03-24
作者: John Gruber
---
```

读取时提取以下字段（如有）：
- `来源` 或 `source`
- `链接` 或 `url` 或 `link`
- `作者` 或 `author`
- `发布时间` 或 `date`

文章标题优先从 frontmatter 的 `title` 字段读取；若无，则取文章正文第一个 `#` 标题；若仍无，则从文件名推断。

### 4. 逐篇生成摘要

对每篇文章生成中文摘要，要求：

- **长度**：5–8 句（或用户指定的 `-n` 句数）
- **语言**：中文
- **内容**：忠实原文核心观点，不添加个人评价，不遗漏重要信息
- **格式**：纯段落，不用列表，不用小标题
- **作者/来源**：若原文有作者或来源链接，必须保留在摘要头部

摘要头部格式（视字段是否存在而定）：

```
**来源**: {来源名} | **作者**: {作者名}
```

或（仅有来源，无作者）：

```
**来源**: {来源名}
```

若有链接，来源名应做成超链接：`[{来源名}]({链接})`。

### 5. 组装输出文档

将所有摘要汇总为一个 Markdown 文件，格式如下：

```markdown
# {目录名或日期} 文章摘要汇总

## 1. {文章标题}

**来源**: [{来源}]({链接}) | **作者**: {作者}

{中文摘要段落}

---

## 2. {文章标题}

...
```

文章编号从 1 开始，按目录中文件的字母顺序排列。

### 6. 写入输出文件

将组装好的内容写入 `<目录>/summarize.md`（或用户指定的 `-o` 路径）。

### 7. 汇报完成

```
✓ 摘要完成：{N} 篇文章
输出文件：{输出路径}
{若有文件读取失败，列出文件名和处理方式}
```

## 质量要求

- 每篇摘要必须真正反映文章内容，不是标题的简单扩写
- 保留原文的核心数据、观点、结论
- 技术术语保留原文或通用译名，不随意创造新词
- 摘要之间用空行分隔，保持阅读节奏

## Known Pitfalls

- 文件名含单引号或特殊字符时 Read 工具会报错 → 用 PowerShell `Get-Content` 兜底
- 部分文章无 frontmatter → 从正文第一段推断来源信息
- 文章极短（< 100 字）→ 摘要可少于 5 句，但不少于 2 句，并如实反映内容简短
