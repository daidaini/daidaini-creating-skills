# 地图技能分批优化记录

日期：2026-10-09。已完成三批，未执行 commit/push。保持 Scaffold，不声明生产发布。

## 第一批：正确性

- 将“大矩形就是 D3 bug”的断言改为坐标、环方向/孔洞、球面面积、投影和库版本的诊断顺序；保留 geoPath 与自动拟合。
- 区分零值和无数据；修复 KML 图标嵌套和蓝色 AABBGGRR 编码。
- 以专用图层类验收，不把路线算成点位，不把瓦片元素存在当加载成功；允许同值指标、仅点位合成、明确标注的两点示意线。
- 统一目录包与明确单文件交付，KML-only 不生成多余 HTML。

## 第二批：减少重复工作

- 新增预检：已声明 CRS/来源日期、坐标/环闭合、区域键唯一性、指标匹配、零值/缺失值、路线与统计字段；渲染副本适配普通局部多边形方向，保留原始 JSON。
- 新增通用 D3/Leaflet 模板，共用数据契约，图层统一拟合；Leaflet 支持无瓦片离线矢量图，移动端 resize 自动重拟合。
- 固定 D3 5.16.0 / Leaflet 1.9.4，缓存命中校验 SHA-256；新增单文件打包并内联 CSS 图像。
- 入口与接口初始加载估算约 984 tokens，通过当前检查器默认 1000-token 门槛；详细材料按需读取。

## 缓存测量

- d3 cold: 968 ms，命中 0，下载 1。
- d3 warm: 60 ms，命中 1，下载 0。
- leaflet cold: 1959 ms，命中 0，下载 5。
- leaflet warm: 62 ms，命中 5，下载 0。

每个渲染器只测一对冷/热获取，受网络与本机性能影响。这里只证明缓存复用减少依赖获取耗时，不能推导完整 agent 任务提速百分比或 token 节省。
