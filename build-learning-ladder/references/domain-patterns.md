# Domain Patterns

## Domain Detection

Determine which domain the topic belongs to **before** writing the 5 levels. This affects:
- Level naming conventions
- Exercise style (build vs. copy vs. repeat vs. explain)
- Common mistake patterns

### Detection Rules

| Domain | Keywords / Signals | Level Naming Style |
|--------|--------------------|--------------------|
| **Technical** | coding, programming, tools, software, frameworks, APIs, databases, DevOps, ML engineering | Project-oriented: "Hello World" → "Ship It" |
| **Creative** | drawing, painting, writing, music, photography, design, film, craft | Voice-oriented: "Copying" → "Expression" |
| **Physical** | sports, cooking, instruments, dance, yoga, martial arts, crafts | Form-oriented: "Form" → "Teaching" |
| **Knowledge** | history, philosophy, science, math, economics, law, theory | Argument-oriented: "Anchors" → "Synthesis" |

### Level Naming by Domain

Use these as inspiration — adapt to feel natural for the specific topic:

| Level | Technical | Creative | Physical | Knowledge |
|-------|-----------|----------|----------|-----------|
| 1 | Hello World | Copying | Form | Anchors |
| 2 | First Project | Understanding | Repetition | Connections |
| 3 | Real Feature | Experimenting | Adaptation | Questions |
| 4 | Architecture | Finding Voice | Flow | Arguments |
| 5 | Ship It | Expression | Teaching | Synthesis |

**If none fit**, use the default names: Complete Beginner → Basic Understanding → Practical User → Problem Solver → Confident Practitioner.

### Hybrid Domains

If a topic straddles domains (e.g., "machine learning" = technical + knowledge, "music production" = technical + creative), lean into the hybrid nature. Note it explicitly:

> "This topic strades technical implementation and conceptual understanding — the ladder reflects both."

For hybrid domains, choose the primary domain for level naming, but adapt exercise types to cover both angles.

### Exercise Style by Domain

| Domain | Exercise Characteristics | Mistake Patterns |
|--------|-------------------------|------------------|
| Technical | "Build X", "Implement Y", debug challenges | Config issues, syntax errors, tooling hell, tutorial hell |
| Creative | "Copy then modify", "Remix X in your style" | Perfectionism, comparison, theory without practice, waiting for inspiration |
| Physical | Repetition drills, form checks, timed practice | Rushing, bad posture/form, skipping warm-up, inconsistent schedule |
| Knowledge | Write an explanation, debate both sides, teach someone | Passive reading, memorization without understanding, confirmation bias |
