# 图题处理

图题的核心是把图中的信息转成可核对的文字，同时保留原图。报告中要写明每个条件来自题干、配图还是学生作答。

## 题目中的配图

- 保存局部截图，并在记录中注明所在照片和位置。
- 提取图中的文字、数值、刻度、标注和位置关系，例如长 8 厘米、宽 3 厘米、虚线表示对称轴。
- 图中的信息与题干冲突时，以题干为准，并把冲突列入待确认。
- 数数题：给物体编号，列出编号和数量，保留编号后的图供家长核对。
- 钟表、数轴、统计图：写出读取的数值，并说明依据哪一条刻度或哪一个格子。
- 几何图形：先提取已知条件，再推理。照片没有可靠比例尺时，不根据像素判断实际长度。

## 学生在图上的作答

- 连线题：识别每条线连接的两个对象，逐条与标准配对对照。线条交叉、起点不清时标为待确认。
- 圈选题：识别实际圈住的对象。划掉重选时，以最后确定的选择为准，并注明有改动。
- 涂色题：识别涂色区域，检查数量、比例或位置是否满足题目要求。涂色边缘有少量超出，可视为合理误差。
- 画图题：检查题目要求的形状和关系，例如对称、平移后的位置、补全另一半。手绘误差可接受，明显不符合要求时判为错误。
- 测量题（画线段、画角）：照片无法可靠测量时，结论标为待确认，并建议家长用尺子核对。

## 不确定时的做法

图形识别仍可能出错。遇到以下情况，结论使用待确认，并写明需要家长复看哪一处：线条或数字被遮挡，图中数量超过十个且难以分辨，连线或圈选互相交叉，照片角度导致形状变形。
