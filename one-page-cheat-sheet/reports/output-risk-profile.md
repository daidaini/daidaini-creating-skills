# Output Risk Profile — One-Page Cheat Sheet

> Generated by yao-meta-skill optimization. Identifies likely output-quality failures before they reach the user.

## Risk Matrix

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Topic too broad → output exceeds one page | **High** | Medium | Preflight check asks user to narrow; Section 2 caps at 7 items |
| Generic headings (topic-agnostic section titles) | **Medium** | High | Template requires concrete, topic-specific headings |
| Vague examples (abstract or contrived) | **Medium** | High | Quality rules require "real-world scenario with context" |
| No visual element (wall of text) | **Low** | High | Section 3 mandates at least one visual; multiple options provided |
| Jargon without explanation | **Medium** | Medium | Must NOT rule: every technical term gets parenthetical definition |
| Output language mismatch | **Low** | High | Preflight: match user's language, output entirely in that language |
| Mermaid diagram too complex | **Low** | Medium | Best-practices reference caps at 15 nodes |
| Too many sections → crammed, unreadable | **Medium** | Medium | One-page constraint forces ruthless cutting |
| Fake or misleading examples | **Low** | High | Examples must be concrete and realistic — no "2+2=4" examples |

## Failure Mode Taxonomy

### Category A: Scope Failures
1. **Topic explosion**: user says "math" → impossible to fit one page → Preflight catches and asks to narrow
2. **Section overflow**: user's topic genuinely has 12+ core concepts → Section 2 cap forces prioritization
3. **Example creep**: too many examples → cap at 5, cut to the most instructive

### Category B: Quality Failures
1. **Generic output**: "This concept is important because it helps you understand" → Must NOT rule against filler
2. **Academic examples**: "Consider a function f(x)..." → Must Do rule for concrete, realistic examples
3. **Theoretical mistakes**: "People might confuse X with Y" but real beginners never do → Mistake selection heuristic

### Category C: Format Failures
1. **No visuals**: Section 3 skipped or minimal → Must Do: at least one visual element
2. **Paragraphs instead of bullets**: Walls of text → Must Do: bullet points
3. **Overlong**: exceeds one page → One-page constraint heuristic in best-practices

## Defensive Measures

| Layer | Mechanism |
|---|---|
| Preflight | Narrow broad topics before generation |
| Inline rules | Must Do / Must NOT Do in SKILL.md |
| Template | 8-section structure enforces completeness |
| References | output-template.md and best-practices.md for detail |
| Self-check | Section 6 checklist catches prerequisite gaps |
