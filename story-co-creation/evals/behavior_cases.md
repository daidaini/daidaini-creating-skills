# 行为回归用例

这些是人工或独立执行环境可复用的验收场景，不是已运行的模型测试。每个场景读取 SKILL.md，从所给对话状态开始，仅完成当前应完成的阶段；不得在测试中调用实际图片生成服务。

| 场景 | 输入或已有状态 | 可观察的通过条件 |
|---|---|---|
| 儿童碎片 | “龙怕高，月亮破了，它用面条补月亮；不要坏人，也不要最后突然学会飞。” | 框架保留四个独特点，不新增反派或飞行结局；补充建议可辨认；等待框架确认，无正文。 |
| 框架通过但篇幅未定 | 上一轮已展示框架，用户：“可以，就这个。” | 下一轮建议篇幅、章节和长度取舍，等待回复；不生成正文，不把此回复记成篇幅确认。 |
| 已有全部文字决定 | 用户已确认具体框架并说“约 2,000 字，直接按这个写”。 | 进入正文；不重复询问已明确字数，不提前配图。 |
| 核心变化 | 用户原设定“机器人不要当国王”，后来要求“最后它登基”。 | 澄清或给合理的核心变化建议，更新框架并确认受影响部分，不静默丢弃原设定。 |
| 篇幅大幅收缩 | 三万字十章框架已通过，用户要求改成一千字。 | 提出压缩框架与删合取舍，等待确认；不在缩写中暗自删掉主要人物。 |
| 正文完成 | 已确认约 3,000 字，已完成并自查正文；未讨论配图。 | 交付正文，建议有理由的配图数量与场景，可不配；不生成实际图片。 |
| 实际数量与建议不同 | agent 推荐三张内文插画，用户：“只要最后告别那张，水彩，不要封面。” | 实际计划恰为一张告别图，无额外封面；记录风格与位置。测试只检查方案，不调用图片工具。 |
| 无图片能力 | 配图方案已确认，但宿主无图片工具。 | 保留完整正文，交付逐图提示词和位置，明确图片未生成；正文无假图片或断链。 |
| 长篇恢复 | 已完成前两章，记录显示云针断了、主角仍怕高，用户说继续第三章。 | 接续已确认计划，不重做问卷；不会恢复云针或无故治好恐高；保存新进展，未写完标为部分完成。 |
| 无文件能力 | 聊天环境，无文件读写工具，用户提供新故事种子。 | 正常输出框架并等待确认；暂停时能给复制恢复摘要，不要求配置文件系统。 |
| 局部修改 | 用户只要求把第二章雨夜改成雪夜。 | 修改必要的天气与连续性，不重写无关人物结局；已配图受影响时标明。 |

文学质量需结合实际全文检查因果、人物、语言与创意保真，不能靠命中标题或关键词宣布通过。
