# 交付、恢复与插画

## 文件交付

默认在用户当前工作目录创建 `{story-slug}/`，遵从用户指定路径和格式。目录重名时先辨别是续写还是另一作品；另一作品使用新目录，不覆盖无关文件。

按阶段逐步生成，不创建空正文或假图片：

- `plan.md`：用户创意与约束、建议补充、最新故事框架、篇幅计划、版本和确认状态。草案允许保存，明确标为待确认。
- `story.md`：纯作品，含标题、必要的章标题和完整正文；分章持续写入。流程问答、统计和提示词放在其他文件。
- `progress.md`：最小恢复记录，首次框架形成时保存，此后在确认、重要修改和每批章节完成后更新。
- `illustrations.md`：只有进入配图讨论时才创建，含场景方案、确认记录、提示词及图片结果映射。
- `images/`：仅保存实际生成且采用的插画，文件名稳定，例如 `scene-01.png`。

插图在正文相关段落之后用相对路径引用，例如 `![小龙第一次见到云海](images/scene-01.png)`。没有实际图片时，只在插画方案记录计划，不往正文插入断链，也不把提示词称为插画。

只能聊天、无文件权限或工具不可用时，直接交付文本，并在批次结束或暂停时给可复制的恢复摘要。不要将文件保存能力当作创作的前提。仅当用户明确要求 HTML、Word、PDF 等格式时，再使用宿主可用的对应能力；不强制依赖其他 skill 或某一厂商 API。

交付消息说明文件位置、完成或部分完成状态、实际统计或估计口径。正文完成后在同一消息询问插画意愿即可，避免先问“满意吗”再问“要插画吗”形成无必要的等待。

## 最小恢复记录

使用普通 Markdown，不需要状态机程序或数据库。记录下面事实即可：

```markdown
作品：云朵修理铺
阶段：等待篇幅确认
创作方式：共同创作
读者与语气：适合 8～10 岁，温暖、带一点悬念
不可改的创意：小龙怕高；云可以缝补
框架：plan.md 第 2 版，用户已确认
篇幅：建议 3,000～4,000 字，待确认
正文：未开始
连续性：尚无已写章节
插画：未询问；未获生成确认
下一步：等待用户选择篇幅
```

长篇加上已完成章节、每章关键变化、当前人物与道具状态、未解决线索、下一章任务。不要保存完整聊天转录或不必要的个人信息。

确认状态只能从实际对话写入，不能把 agent 自己的建议记成用户批准。明确保存确认对应的框架版本、篇幅范围、插画数量与方案；不同事项可以在同一回复中确认。

恢复时先读计划、进展和相关正文；有冲突以用户最新明确要求为准，说明并修正过时记录。不确定是否确认时只问缺失那一项，不重启整套问卷。

## 字数口径

预估只能标为“预计约”，不承诺精确数量。中文默认按正文中的汉字数量计，不含标题、标点、空白和图片链接；混合语言或用户指定其他口径时，在篇幅确认阶段说明。英文按正文单词计，不把 words 混成汉字数。

有文件和可执行工具时，对最终正文按声明口径统计；可用工具现场计数，不要求安装专用依赖。无法可靠统计时标为“估计”，不能伪称“已统计”。若用户要求精确字数而环境无法计数，应说明限制并协调可交付范围。

分批长篇同时关注每章与总量，不能前几章消耗全部篇幅；最终统计只包括实际交付的正文。超出已确认范围先在原框架内修整，结构性增删再交由用户决定。

## 插画方案与确认

完整正文完成后，结合实际故事提出有理由的建议，而不是每章固定一张。可推荐一个数量以及少量备选场景，让用户能减到一张或选择不配图。封面算不算在总数内要说清楚，不能暗中多生成。

方案列出每张图的场景、插入位置、表现目的；同时建议风格、人物外观及需要的画幅。例：“建议 3 张内文插画，不含封面，分别画初遇、失败后的合作、最后告别；也可以只选告别那张。”

只有用户已明确实际数量、场景及风格（或明确授权使用所提建议）才调用图片工具。已在前文明确给出的决定沿用，不重复询问；缺信息时一次给一份可接受的具体方案。

## 生成与一致性

检查宿主真实提供的图片生成能力。有可用图片 skill/工具时遵循其操作要求；不硬编码工具名、模型、API key 或只在某个 harness 可用的绝对路径。

生成前，从正文和已确认方案整理小型视觉设定：角色体貌、衣着、关键道具、画风与色调。文字中未出现但必须可视化的细节，在配图方案一起提出；图像不能自行增加故事事实。

每张提示词含主体、动作、环境、构图、风格、固定外观及需避免的偏差。有参考图能力时复用已采用图片帮助保持外观；不承诺绝对一致。外观和场景不符时针对偏差修正，不借修图重写故事。

生成后查看图片，核对角色、事件、数量、画风和正文的一致性，保存实际采用文件并检查正文链接。图片不可见时说明尚未完成视觉核对。修改已有配图保留可恢复版本；不要把失败的批次记为全部完成。

无图片工具或生成失败时，保留正文，交付确认方案及可供其他工具使用的逐图提示词，明确“尚未生成图片”。报告已成功和未完成的数量，不暗中安装工具、调用付费外部接口或反复重试增加数量。
