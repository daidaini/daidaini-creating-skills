# 输出风险

| 易错点 | 对应约束 | 检查方式 |
|---|---|---|
| 替孩子改掉独特想法，硬加教育寓意 | 区分原始设定与建议，不纠正幻想为现实 | 碎片创意与最终框架、正文逐项对照 |
| 框架通过后直接写作或自动出图 | 框架、篇幅和插画分别记录明确决定 | behavior_cases.md 的逐阶段用例 |
| 所谓详细故事只是长提纲 | 关键场景展开行动、对话与选择 | 检查实际场景、因果和结局，而非标题数量 |
| 文字成人化、词句高深，或为易懂而刻意幼稚化 | 默认儿童文学风格，常见词与具体画面，逐段朗读检查 | 儿童文学语言与年龄未知用例；检查全文可理解性，不靠禁词表打分 |
| 估算被说成精确字数 | 声明语言与统计口径，区分估计和实测 | 比较正文统计与确认范围 |
| 长篇忘设定或只写一章就宣布完成 | 保存连续性、下一章任务和部分完成状态 | 中断恢复场景 |
| 推荐三张却生成更多，或假装已有图片 | 确认实际数量，保存真实文件，无工具交提示词 | 方案、实际文件数量及正文链接核对 |
| 插画人物与文字不一致 | 固定视觉设定，复用参考图并查看实际结果 | 人工或具备视觉能力的工具核对 |

此表预测风险并定义约束，不代表实际文学质量或图片一致性已经验证。
